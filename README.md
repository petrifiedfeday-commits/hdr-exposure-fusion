# Инструмент HDR-объединения нескольких снимков с разной экспозицией
**Курс:** Компьютерное зрение 1 (РК2)  
**Вариант:** 5  
**Датасет:** Достопримечательности и ландшафты Казахстана (Чарынский каньон, Озеро Каинды, Заилийский Алатау/Медеу, Монумент Байтерек)

---

## 1. Постановка задачи и обоснование
Цифровые сенсоры обладают ограниченным динамическим диапазоном, из-за чего сцены с высоким перепадом яркости (ночная иллюминация городов, глубокие каньоны, снежные вершины) неизбежно содержат клиппинг в светах или потерю деталей в тенях.

В рамках проекта реализован модульный пайплайн объединения экспозиционных брекетингов:
1. **Неделя 1 (Базовая реализация):**
   * Выравнивание со штатива `AlignMTB` (Ward's Median Threshold Bitmap);
   * Пирамидальное слияние экспозиций Тома Мертенса (`Mertens Exposure Fusion`);
   * Объективная оценка динамического диапазона: энтропия Шеннона ($H$) и доля клиппинга пикселей ($Y < 5$ и $Y > 250$).
2. **Неделя 2 (Максимальный балл и потоковый режим):**
   * Выравнивание со съёмки с рук через ключевые точки `SIFT` и проективную гомографию `RANSAC` ($H \in \mathbb{R}^{3 	imes 3}$) с устранением артефактов качания камеры;
   * Физическая реконструкция функции отклика камеры (CRF) и 32-битной карты физической яркости (`Debevec HDR`) с тон-маппингом (`Reinhard`, `Drago`);
   * Потоковый видеопроцессор серийной съёмки (скользящее окно `deque`) со скоростью **>20 FPS** на CPU.
3. **Неделя 3 (Устранение артефактов движения — De-ghosting):**
   * Детекция динамических объектов (`detect_motion_mask`) через эквализацию гистограмм и морфологическую фильтрацию;
   * Бесшовное альфа-замещение силуэтов из опорного кадра 0 EV (`merge_mertens_deghosted`);
   * Консольный инструмент пакетной конвертации директорий `batch_process.py`.

## 2. Структура репозитория

```text
├── hdr/
│   ├── __init__.py           # Инициализация пакета
│   ├── alignment.py          # Выравнивание (AlignMTB, SIFT+RANSAC)
│   ├── merging.py            # Слияние (Mertens, Debevec, Tonemapping)
│   ├── metrics.py            # Расчет энтропии и клиппинга
│   ├── realtime.py           # Потоковая обработка видео и замер FPS
│   └── deghosting.py         # Устранение артефактов движения (De-ghosting)
├── notebooks/
│   └── HDR_Project_Colab_RK2.ipynb  # Полный Colab блокнот (3 недели)
├── batch_process.py          # Консольная пакетная обработка
├── requirements.txt          # Зависимости
├── .gitignore
└── README.md                 # Документация проекта
```

## 3. Инструкция по запуску в Google Colab
1. Откройте блокнот `notebooks/HDR_Project_Colab_RK2.ipynb` в Google Colab.
2. В верхнем меню выберите **Среда выполнения → Выполнить всё**.
3. Все 5 фотографий Казахстана загрузятся автоматически, построятся графики выравнивания, слияния, замера скорости и устранения призраков на ночном Байтереке.
